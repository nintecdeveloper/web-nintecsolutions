# Nintec brand assets

Transparent outlined SVG assets; no external font or image dependencies.
- nintec-logo-horizontal-light.svg: dark lettering for white/light backgrounds.
- nintec-logo-horizontal-dark.svg: white lettering for dark backgrounds.
- nintec-icon.svg: circuit-only icon.
- favicon.png (64px), apple-touch-icon.png (180px), nintec-icon.png (512px): transparent icon fallbacks.
- social-card.png: 1200×630 OG image with the dark-background brand variant.

The circuit was redrawn as vector paths from the supplied Nintec reference. Typography is outlined Arial Bold/Arial, with spaced uppercase secondary lettering. Source images remain untouched. Regeneration: scripts/build_brand.py requires fonttools, cairosvg, Cairo and the system Arial fonts; none are required for normal website builds.
